# 2️⃣ MASTER CHECKLIST (End-to-End)

## ✅ A. DSA (NON-NEGOTIABLE)

### 🔹 Must-know Topics (Interview level)

#### Arrays / Strings

* Sliding Window (fixed + variable)
* Two Pointers
* Prefix Sum
* Kadane
* Frequency maps

#### Linked List

* Reverse (iterative + recursive)
* Cycle detection
* Merge sorted lists
* LRU Cache (VERY IMPORTANT)

#### Stack / Queue

* Monotonic Stack (Next Greater)
* Valid Parentheses
* Min Stack
* Queue using Stack

#### Trees

* DFS / BFS
* Level order
* Diameter
* LCA
* BST validation
* Serialize / Deserialize

#### Graphs

* BFS / DFS
* Topological sort
* Shortest path (BFS / Dijkstra)
* Cycle detection

#### Recursion / Backtracking

* Subsets
* Permutations
* Combination Sum
* N-Queens (logic)

#### Dynamic Programming

* 0/1 Knapsack
* LIS
* Coin Change
* DP on strings
* DP on grids

#### Heaps

* K largest/smallest
* Top K frequent
* Merge K sorted lists
